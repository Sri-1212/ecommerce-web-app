# E-Commerce Web Application

A full-stack e-commerce web application with product catalog, authentication, role-based access control, shopping cart, checkout, order management, stock management, and PostgreSQL database integration.

## Live Demo

**Frontend:** https://ecommerce-web-app-rosy.vercel.app/products

**Backend API:** https://ecommerce-web-app-kece.onrender.com/api/health

## GitHub Repository

This repository contains the complete source code for the frontend and backend of the application.

## Key Features

- User registration and login
- JWT-based authentication
- Role-based access control (User / Admin)
- Product catalog and product details
- Admin product CRUD operations
- Search and category filtering
- Guest shopping cart
- Persistent user shopping cart
- Guest-to-user cart merging
- Checkout and order creation
- Order history and order details
- Admin order management
- Order status updates
- Stock management
- Transactional checkout with PostgreSQL
- Responsive frontend
